# MediaManager 截图指南

请提供以下 6 张 PNG 截图。收到图片后，可以直接放入本目录并更新项目主页。

## 截图要求

- 推荐尺寸：`1440 × 900` 或 `1600 × 1000`。
- 使用 PNG。
- Windows 显示缩放建议为 100% 或 125%。
- 尽量使用测试媒体，不暴露私人目录、邮箱、Token 或真实姓名。
- 截图前清空 TMDB Token 输入框，Token 的任何一部分都不能出现在图片中。
- 保持同一种窗口尺寸和主题。
- 截图前关闭详情页中的私人备注。

## 必需截图

### 1. `library-overview.png`

- 打开“全部影片”。
- 展示至少 6 个海报。
- 同时出现已看和未看徽标。
- 左侧导航、搜索框和排序筛选都应可见。

### 2. `media-detail.png`

- 打开一个资料完整的影片详情。
- 展示海报、标题、分类、简介、文件参数和操作按钮。
- 路径如包含隐私信息，请先使用测试目录。

### 3. `anime-scraping.png`

- 打开一个动画详情。
- 使用中文关键词执行在线搜索。
- 保留 Bangumi 和 AniList 候选结果列表。

### 4. `batch-management.png`

- 进入批量管理模式。
- 选中多个条目。
- 展示批量刷新、主条目、合并和删除工具栏。

### 5. `data-safety.png`

- 打开“管理 → 数据安全”。
- 展示资料库备份、恢复和媒体路径迁移区域。
- 不要显示私人真实路径。

### 6. `diagnostics.png`

- 打开“管理 → 日志与诊断”。
- 展示数据库统计、ffprobe 可用状态和日志区域。
- 日志中不要包含私人目录。

## 可选截图

- `blacklist.png`：黑名单恢复界面。
- `scan-progress.png`：正在扫描时的实时进度。
- `tags-collections.png`：标签和片单管理。
- `installer.png`：Windows 安装界面。
