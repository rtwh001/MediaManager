MediaManager 0.1.0 Portable / 便携版
====================================

中文
----
1. 将整个压缩包解压到一个可写目录。
2. 双击 media-manager.exe。
3. 不要只复制 exe；binaries 和 third-party 目录必须保留在旁边。
4. 用户资料仍保存在：
   %LOCALAPPDATA%\com.local.mediamanager\
5. 便携版不会创建开始菜单快捷方式。需要快捷方式时，请使用安装版。

English
-------
1. Extract the complete archive to a writable folder.
2. Double-click media-manager.exe.
3. Do not copy the executable alone. Keep the binaries and third-party
   directories beside it.
4. User data is still stored under:
   %LOCALAPPDATA%\com.local.mediamanager\
5. The portable build does not create Start menu shortcuts. Use the installer
   if you want normal Windows integration.
